Vesper Bay is a browser-playable 2D open-world crime game inspired by classic GTA: explore a sun-soaked city on foot and by car, steal vehicles, face traffic and police wanted levels, complete missions and story beats, and use a HUD with minimap — all original content, playable offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

To generate the submission dossier locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
