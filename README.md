# Vesper Bay

**Vesper Bay** is a 2D open-world crime game built for the GTA6-01 competition.

## Features
- **Open-World Exploration**: Navigate the city of Vesper Bay.
- **Driving**: Hijack vehicles and navigate traffic.
- **Combat & Police**: Wanted system with responsive AI police.
- **Missions**: Dynamic mission system.
- **HUD**: Integrated minimap and status display.

## Running Locally
1. Serve the game: `node serve.ts`
2. Open `http://localhost:8080` in your browser.

## Building
To build for submission:
```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```
